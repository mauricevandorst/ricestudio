# Parallax Gallery Template

Bare minimum template met alleen:

- `parallax-gallery.html`
- `parallax-gallery.js`

## Gebruik

1. Kopieer beide bestanden naar je project.
2. Zorg dat Tailwind al in je project actief is.
3. Vervang de afbeelding-data in `GALLERY_IMAGE_COLUMNS` in `parallax-gallery.js`.
4. Zet de HTML-sectie uit `parallax-gallery.html` op de plek waar je de gallery wilt tonen.

## Instelbaar

- `data-distance-mobile`
- `data-distance-desktop`
- `data-distance-breakpoint`
- Per kolom: `data-direction` en `data-speed`

Alles draait op vanilla JavaScript en Tailwind utility classes.
